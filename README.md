# Apache Kafka Hands-On

Ejercicios prácticos y proyectos para aprender Apache Kafka, Docker y 
aquitecturas event-driven.


## Sobre el proyecto

Este repositorio contiene ejercicios para comenzar a desarrollar mientras
aprendo Apache Kafka y tecnologías relacionadas.

El objetivo de este proyecto es comprender Kafka desde una perspectiva práctica,
comenzando con workfloes básicos de producer-consumer, introduciendo topics, particiones, 
grupos consumidores, réplicas y otros conceptos relacionados con Kafka.


## Tecnologías usadas en este proyecto

- Apache Kafka
- Docker
- Docker Compose
- Java
- Git
